# 🤖 Personal Chat Assistant

A beginner-friendly chatbot built using Python that responds to basic questions about Python, AI, Machine Learning, and Computer Science.

## ✨ Features

* 💬 Interactive conversation
* 👋 Greeting responses
* 🐍 Basic Python information
* 🤖 Basic AI information
* 🧠 Basic Machine Learning information
* 💻 Basic CSE information
* 🔄 Continuous conversation
* 🚪 Exit using `bye`
* 📝 Displays the user's question before the response

## 🛠️ Technologies

* Python

## 🧠 Concepts Practiced

* Functions
* Variables
* User input
* `if / elif / else`
* `while` loop
* String handling
* Basic chatbot logic
* `break` statement

## ▶️ How to Run

```bash
python chatbot.py
```

