# Personal Finance App – Expense Tracker

## 📌 About the Project

A simple Python-based Personal Finance App that helps users record and manage their daily expenses.

## ✨ Features

* Add expenses
* View recorded expenses
* Calculate total expenses
* Categorize expenses
* Simple command-line interface

## 🛠️ Technologies Used

* Python

## ▶️ How to Run

1. Open the project folder in VS Code.
2. Open the terminal.
3. Run the following command:

```bash
python expense_tracker.py
```

4. Enter the required expense details.
